# Weather App 🌤️

A simple and responsive Weather Application that allows users to search for real-time weather information of any city.

## 🚀 Features

- Search weather by city name
- Displays current temperature
- Shows weather conditions and icons
- Displays humidity
- Displays wind speed
- Error handling for invalid city names
- Loading state while fetching data
- Supports Enter key for searching
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeather API

## 📸 How It Works

1. Enter a city name in the search box.
2. Click the Search button or press Enter.
3. The application fetches real-time weather data using the OpenWeather API.
4. Weather information is displayed dynamically on the screen.

## 🔗 API

This project uses the OpenWeather API to fetch real-time weather data.
